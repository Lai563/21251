# 《勿聲》HUSH

> 看得見的代價，是被聽見。

一款以**麥克風音量**為唯一控制器的第一人稱聲音恐怖遊戲。你必須出聲，才能用回聲「看見」漆黑的空間；但每一次出聲，都會引來只聽得見你的「聽者」。

## 快速開始

需求：Node.js 20+、Chrome / Edge / Firefox 桌面版、麥克風（可选）。

```bash
cd hush
npm start
```

開啟 <http://127.0.0.1:5173>。第一次開始會要求麥克風權限並進行 15 秒環境校準；沒有麥克風可切換**鍵盤模式**（按住空白鍵模擬音量），完整可通關。

> 請勿直接雙擊 `index.html`：ES Modules 需要 HTTP 伺服器。`npm start` 已內建零依賴靜態伺服器。

## 操作

| 操作 | 按鍵 |
|---|---|
| 移動 | W A S D / ↑ ↓ |
| 轉向 | 滑鼠（點擊畫面鎖定）／← → ／ Q E |
| 發聲 | 直接對麥克風說話；鍵盤模式按住空白鍵 |
| 暫停 | Esc |

音量越大，聲納照得越遠；但怪物也聽得越清楚。氣息歸零會強制喘氣 3 秒——那是你唯一的「裝彈時間」。

## 四章

1. **醒** — 地下鍋爐室：學會低聲照路與氣息管理。
2. **走廊** — 療養院主棟：學會吼叫震退與聲紋誘餌。
3. **水室** — 淹水的地下層：水讓聲音傳得更遠，風險加倍。
4. **聽者** — 教堂式中庭：在祭壇前連續吼叫，壓過牠的聲源。

## 隱私

- 麥克風只用來計算即時 RMS 音量。
- **不錄音、不儲存音訊、不上傳、不連網**。
- 校準結果與進度只存在瀏覽器 `localStorage`。

### 結構

```
index.html / styles.css      畫面與 HUD
js/core/config.js            共用常數（凍結）
js/core/*.js                 純邏輯：音量、氣息、聲紋、玩家、射線、關卡、AI、Session
js/audio.js                  麥克風擷取、校準、鍵盤替代
js/audio-feedback.js         程序化環境音與事件音效
js/input.js                  鍵盤／滑鼠／指標鎖定
js/renderer.js               Canvas 2D 第一人稱聲納渲染
js/ui.js / js/game.js        DOM UI 與遊戲狀態機
docs/                        企劃、產品規格、驗收標準、測試計畫、架構
tests/                       單元與整合測試
```

技術細節與模組合約見 [`docs/architecture.md`](docs/architecture.md)。

## 無障礙

- 字幕可開關；所有聲音事件皆有視覺提示。
- 鍵盤模式完整可通關，無需麥克風。
- 「降低動態」可關閉畫面震動、撕裂與閃爍。
- 聲量、氣息、危險皆有視覺化回饋。
